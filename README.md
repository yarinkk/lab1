# Система обліку витрат (Lab 7)

## Опис
Цей проєкт є простою системою обліку витрат.
Він дозволяє додавати транзакції, переглядати їх та обчислювати загальну суму витрат.

## Функціонал
- Додавання транзакцій
- Перегляд списку витрат
- Обчислення загальної суми
