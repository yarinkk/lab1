# Lab 5
## Опис
Програма для розрахунку вартості доставки в інтернет-магазині.
## Функції
- calculate_weight_cost — розрахунок за вагою
- add_express_fee — доплата за терміновість
- calculate_total_cost — загальна ціна
## Запуск
python lab5/app.py
## Тести
python -m unittest lab5/test_app.py
## Doctest
python -m doctest lab5/app.py -v
